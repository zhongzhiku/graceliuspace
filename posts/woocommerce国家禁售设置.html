WordPress + WooCommerce 跨境禁售设置指南：从全局到单品的3大方案

1. 全局一刀切：彻底关闭特定国家销售通道

适用场景： entire shop 不打算做某国生意，比如物流成本高到离谱的地区

路径： WooCommerce → 设置 → 常规 (General)

操作步骤：

  • 找到 “销售地点” (Selling location(s))
  • 选 “向特定国家销售，除了...”，输入禁售国家
    or
  • 选 “销售给特定国家”，只填允许的国家
  • 配送地点 (Shipping location(s)) 建议选 “配送至所有你销售的国家”

效果： 结账页国家下拉菜单直接 隐藏禁售选项，用户根本看不到，想下单都没门

2. 配送卡脖子：用物流限制变相禁售

适用场景： 想留个口子（比如允许本地自提），但不想发快递到某国

路径： WooCommerce → 设置 → 配送 (Shipping) → 配送区域 (Shipping zones)

操作步骤：

  • 只添加目标国家为配送区域（比如 美国、英国、澳大利亚）
  • 绝对不要添加禁售国家（比如 俄罗斯、巴西，别问为什么，清关你懂的）

效果： 用户填完地址会看到 “没有任何配送方式适用于您输入的地址”，比直接隐藏更柔和，但同样能挡单

3. 单品精准打击：特定产品只对部分国家开放

适用场景： 比如 电池、液体 这类敏感品，在欧盟需要 CE 认证，没认证就只能禁售

必须插件：

  • Country Based Restrictions for WooCommerce（免费版够用）
  • WooCommerce Product Restrictions by Location（付费功能更全）

操作流程：
产品编辑页 → 找到新出现的 "Country Restrictions" 选项栏 → 选 "Exclude" → 勾选禁售国家

效果： 该产品在禁售国家 IP 下显示 “不可购买”，其他地区正常销售

4. 终极拦截：连网站都不让他看（GeoIP 玩法）

适用场景： 某国恶意下单太多，或者法律风险极高（比如 伊朗、朝鲜）

2种实现方式：

  • Cloudflare WAF： 防火墙规则 → 国家/地区匹配 → 直接 “阻断” 流量
  • WooCommerce 地理定位： 设置 → 常规 → 默认客户位置 → 开启 “Geolocate”，自动识别用户所在国并应用限制

💡 Grace 的避坑私房话

  1. 别光搞技术，法律擦屁股更麻烦： 在 Shipping Policy 页面 明明白白列出禁售国家，别等客户填完信用卡才说不行，搞不好会被投诉欺诈
  2. 支付网关是最后一道坎： 比如 Stripe 不支持 尼日利亚，你就算开了销售权限，客户也付不了款，白折腾
  3. 建议组合拳： 全局禁售 + 配送限制 双保险，毕竟 WooCommerce 偶尔会抽风，多一道门少一堆事
